# MYAIGURU Trainer Dashboard Prototype

A responsive React + Vite frontend prototype for the AI-Powered Learning Delivery & Trainer Assistant case study.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Included screens
- Dashboard overview
- Batch management
- Learning content studio (simulated lesson draft)
- Assignment management and trainer review interaction
- Quiz builder (sample generated question)
- Learner progress
- Program report preview
- AI Trainer Assistant (simulated chat; no live AI API)

## Important prototype notes
- This is a frontend-only demonstration using illustrative/mock data.
- The case-study baselines shown are 120 learners, 78% attendance, 62% on-time assignment submission, and 4 days average feedback time.
- Batch-level values and AI insights are illustrative, not verified company data.
- No backend, database, authentication, or external AI model is connected.
- AI-generated content and evaluation are represented as drafts/suggestions and require trainer review.
